# Content Guide (daily use)

This repo uses Hugo + Blowfish. For daily edits, focus on `content/`.

## Where to edit

- Homepage: `content/_index.md`
- About page: `content/pages/about.md`
- Projects: `content/projects/`
- Images/files: `content/attachments/`

## About `_index.md`

Hugo uses `_index.md` to define section landing pages. The homepage and `projects/` both rely on `_index.md` files.
