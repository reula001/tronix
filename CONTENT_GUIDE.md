# Content Guide (daily use)

This repo uses Hugo + Blowfish. For daily edits, focus on `content/`.

## Where to edit

- Homepage: `content/_index.md`
- Standalone pages: `content/pages/`
- Projects: `content/projects/`
- Notes: `content/notes/`
- Images/files: `content/attachments/`

## About `_index.md`

Hugo uses `_index.md` to define a section landing page. This is required for the homepage and for sections like `projects/` and `notes/`. These files are normal Markdown and safe to edit.
